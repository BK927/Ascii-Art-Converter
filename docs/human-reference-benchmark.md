# Human Reference Benchmark Candidate Sources

This document tracks candidate material for an anime-character ASCII benchmark.
Do not vendor or commit third-party image/ASCII assets until the license and
redistribution rights are checked per asset.

## Goal

Build a benchmark for improving AA Converter toward human artist-like
structure-based ASCII output. The ideal sample is:

- input image or line drawing
- human-made ASCII target
- rendered target image with known font/settings
- source URL and explicit reuse permission

The open web has many anime ASCII examples, but very few safe, redistributable,
paired `input -> human ASCII` samples. Treat this file as a candidate manifest,
not as a cleared dataset.

## Tier A: Paired Samples That Are Usable Now

None found with enough certainty for direct inclusion as human-authored
`input -> ASCII` benchmark assets.

The safe path is to commission or request permission for 8-12 paired samples:

- license: CC-BY 4.0 or project-specific permission
- deliverables: `input.png`, `artist_ascii.txt`, `artist_render.png`
- font and rendering settings documented
- permission to store samples in this repository or a public benchmark package

## Tier B: Research Seed, Not Human Target

DeepAA is useful because it is directly in the same problem space. It includes
23 sample input line images and 23 generated ASCII-like image outputs. The README
states the provided pretrained models and other files are MIT licensed, and the
paper says the method trains from human-made ASCII art. However, the visible
sample outputs are generated by CNN, not human-authored targets.

Use this for pipeline comparison and evaluator scaffolding, not as the final
human target benchmark.

Source:

- repo: https://github.com/OsciiArt/DeepAA
- paper: https://nips2017creativity.github.io/doc/ASCII_Art_Synthesis.pdf
- original image URL pattern:
  `https://raw.githubusercontent.com/OsciiArt/DeepAA/master/sample%20images/original%20images/NN%20original.png`
- generated image URL pattern:
  `https://raw.githubusercontent.com/OsciiArt/DeepAA/master/sample%20images/images%20generated%20with%20CNN/NN%20generated.png`
- `NN`: `01` through `23`

## Practical Benchmark Plan

1. Use DeepAA's 23 sample pairs to build the benchmark harness quickly.
2. Use Safebooru/Danbooru and Anime AA links only for visual/style analysis.
3. Ask 2-3 ASCII artists for permission or commission 8-12 clean paired samples.
4. Use Wikimedia/ToonOut/Pixabay only as input pools when their per-asset terms
   are compatible.
5. Once 8+ cleared human pairs exist, tune AA Converter against those instead of
   eyeballing presets.
